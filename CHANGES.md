- Trust model (read this first)
  - Signatures prove identity, not content accuracy. A follower's content claims (titles, provider IDs, runtime, etc.) are taken at face value.
  - Provider-ID dedup trusts those claims — a follower advertising Tmdb=603 can dedup into any local/other-peer Movie with Tmdb=603, regardless of what the actual content is.
  - Admins vet followers manually (PATCH /Admin/Followers/Requests). The social layer is the trust layer; only approve peers whose content claims you trust.
  - Only approved followers see real outbox data; non-followers and unsigned requests get empty collections.

- /Federation API (all changes gated behind config feature flag)
  - /Admin (requires elevation)
    - /Followers
      - /
        - GET: returns list of followers
        - DELETE: removes follower (actorUrl query param)
          - success: 204
          - not found: 404
      - /Requests
        - GET: returns list of follow requests
        - PATCH: accepts or rejects follow request (actorUrl query param, { Accept: bool } body)
          - success: 204
          - no pending request: 404
    - /Following
      - /
        - GET: returns list of followed actors
        - DELETE: unfollows actor (actorUrl query param)
          - success: 204
          - not found: 404
      - /Requests
        - GET: returns list of outbound follow requests
        - POST: send a follow request (actorUrl query param)
          - success: 204
          - already following: 409
          - remote actor fetch failed: 502
  - /Actor
    - GET: produces an actor document
      - ensures keypair, produces doc
  - /Inbox
    - POST: receives incoming activity
      - checks valid signature, 401 if invalid
      - delegate to FederationService
  - /Outbox
    - GET: gets paginated OrderedCollection of library updates (page + limit query params)
      - checks valid signature, empty collection if invalid
      - delegate to FederationService

- FederationPeerService
  - HandleFollowRequestAsync(actorUrl)
    - checks if existing inbound request (either pending or rejected) with actorUrl, skips if yes
    - stores inbound request with actorUrl
  - SendFollowRequestAsync(actorUrl)
    - checks if already following the actor, or request already exists. skips if yes
    - fetches remote actor immediately
      - fails if error, empty actor, missing inbox, outbox or public key
    - creates actor entry if it doesn't exist
    - creates follow request referencing actor
    - queues follow activity delivery
  - VetFollowerAsync(actorUrl, accept)
    - fetches inbound, not responded follow request from actor. fails if nil
    - sets request.responded = true (prevents re-vetting)
    - if rejecting, queue rejection delivery, save and stop
    - fetches actor immediately
    - queues a accept{follow} for delivery
  - HandleFollowingAcceptedAsync(actorUrl)
    - fetches outgoing follow request for actorUrl, not responded. fails if nil
    - marks as responded
    - fetches actor from db, fails if not present
    - creates following obj referencing actor
    - backfill enqueued
  - HandleFollowingRejectedAsync(actorUrl)
    - fetches outbound follow request for actorUrl, not responded. fails if nil
    - marks as responded, end.
  - GetFollowersAsync() - self descriptive
  - GetFollowingAsync() - self descriptive
  - GetFollowerRequestsAsync() -> GetPendingRequestsAsync(inbound)
  - GetFollowingRequestsAsync() -> GetPendingRequestsAsync(outbound)
  - GetPendingRequestsAsync(direction)
    - fetches requests from most recent to least recent, not responded
  - RemoveFollowerAsync(actorUrl)
    - fetches follower by actorUrl. fails if nil
    - deletes the object
  - RemoveFollowingAsync(actorUrl)
    - fetches following by actorUrl. fails if nil
    - queues an Undo{follow}
    - deletes the object

- FederationService
  - GetOutboxAsync(page?, limit, signingActorUrl?)
    - checks if actorurl is an approved follower
      - returns empty collection if not
    - checks if page arg is null
      - if it is, build summary outbox response with item count, first page url
      - else build page with total item count, then paginated items in date DESC order
  - HandleInboxActivityAsync(request)
    - actor-on-behalf-of-self verification, uses verified actor signature against actor in body
    - switches on request type
      - follow: PeerService.HandleFollowRequestAsync
      - accept: PeerService.HandleFollowingAcceptedAsync
      - reject: PeerService.HandleFollowingRejectedAsync
      - undo: one level deeper level AOBOS check, then PeerService.RemoveFollowerAsync
      - create, update, delete: LibraryIngester.IngestAsync

- FederationLibraryIngester
  - IngestAsync(activity)
    - check if is a followed actor
    - switches on activity type
      - create, update: HandleCreateOrUpdateAsync
      - delete: HandleDeleteAsync
  - HandleCreateOrUpdateAsync
    - gets the activity's object and validates it's a Video activity, else returns
    - check mediatype tag on the video, validates it's a Movie, else return (MVP)
    - extracts sourceid from video, if nil returns
    - tries to find an existing movie in the db from this actor with this source id
      - if it exists
        - check externalid to make sure this movie is owned by that instance and not another (or local for example)
            - else return
        - ApplyMovieMetadata
        - get parent or throw (log with actionable input)
        - update the item (UpdateItemAsync)
        - return
      - else if it exists but is orphaned, delete the stale item to ingest as a new movie
      - dedup against an existing item with provider id (imdb etc)
      - if it exists, make a FederationIngestedItem linking to it, return
      - else, create the Movie from scratch
  - FindExistingItemByProviderIds
    - extracts provider ids from video object
    - if no providers, return nil
    - queries library for any Movie matching ANY of those ids (TMDB OR IMDB OR ...)
      - note: provider-ID dedup is only as trustworthy as the peers you follow
    - returns first result or null
  - ExtractProviderIds
    - gets all tags that are typed as PropertyValues, not MediaType or Year, not nil
    - returns a [tag: value]
  - HandleDeleteAsync
    - checks if object of activity is a Tombstone, else returns
    - extracts source id from the object, returns if nil
    - gets the ingested item matching this id, returns if nil
    - deletes the ingested item
    - removes the base item if no other ingested items reference it and its external id signals it's not locally available
  - EnsureActorFolder
    - checks for an existing folder for that actor, creates one if not present
  - EnsureFederatedRoot
    - checks for an existing folder for federated content, creates one if not present
  - ApplyMovieMetadata
    - sets name, overview, production year, runtime ticks and providers for a movie from an activitystream object
  - ExtractYear: gets the Year tag if present, parses an int value
  - ParseIsoDuration: iso string to timespan, null if null or error
  - ExtractSourceId: removes {actor}/Items/ from objectId, nil if prefix missing or tail is not a GUID
